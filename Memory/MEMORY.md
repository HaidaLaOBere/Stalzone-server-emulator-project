## STANDING NOTE (from Part 109, still in force)

Never assert a new sequential ordinal for the Reichstag-corroboration count. Multiple real,
independent sources across many parts have confirmed the Reichstag battlefield/event by name, but
the project's own running count of "which numbered corroboration this is" had already diverged
inconsistently before Part 109 caught it. Every part since has disclosed new Reichstag ties as
"just another entry in the long corroboration chain" with NO new number attached. Preserve this
framing in any future edit to these files.
